# Pearl AI · Sale Page — ชุดของแจกหน้าขายด้วย AI

สร้างหน้าขาย (sale page) หน้าเดียวจบ ด้วย AI ในวันเดียว — ไม่ต้องเขียนโค้ด ไม่ต้องจ้าง พร้อมฟอร์มรับออเดอร์ที่ตก Google Sheet อัตโนมัติ และลิงก์ส่งปิดการขายในแชทได้ทันที

ชุดนี้เป็นของแจกประกอบอีบุ๊ก **"หน้าขายด้วย AI เล่ม 01 · หน้าเดียวจบ ส่งลิงก์ปิดการขายในแชท"** โดย Work With AI Lemon

## เว็บตัวอย่างจริง (เปิดดูได้เลย)

**https://stunning-melba-27d262.netlify.app/** — หน้าขายกาแฟดริป "อบเบอร์ 9 / Drip No.9" ที่สร้างด้วยชุดนี้ทั้งหมด deploy บน Netlify แผนฟรี

## ในชุดมีอะไร

| โฟลเดอร์ | คืออะไร |
|---|---|
| `skill/sale-page/` | **skill หน้าขาย** — คู่มือทำงานที่ทำให้ AI ถามก่อน โชว์แผนก่อน ห้ามแต่งข้อมูล ติดตั้งกับ Claude Code หรือแปะเข้าแชท AI ตัวไหนก็ได้ |
| `example-drip-no9/` | **ตัวอย่างเต็มจากงานจริง** — หน้าขายอบเบอร์ 9 (HTML ไฟล์เดียว) + Working Brief + คูมือเชื่อม Google Sheet 10 นาที |
| `sample-result-skill/` | ตัวอย่างผลลัพธ์แบบไม่ใช้ระบบ — เทียบให้เห็นว่าสั่ง AI ลอย ๆ ได้อะไรกลับมา |

## เริ่มใช้ใน 3 ขั้น

1. **อ่าน skill** — เปิด `skill/sale-page/SKILL.md`
2. **แปะให้ AI** — ก๊อปเนื้อหาทั้งหน้าไปวางในแชท AI ของคุณ พร้อมบอก "ทำตามกฎในคู่มือนี้ทุกข้อ ห้ามสร้างอะไรก่อนฉันยืนยัน spec" (ถ้าใช้ Claude Code วางโฟลเดอร์ไว้ที่ `.claude/skills/sale-page/` แล้วเรียก `/sale-page`)
3. **ตอบคำถาม 7 ข้อ** — ประเภทหน้า · สิ่งที่ขาย+จุดขาย · ราคา/แพ็คเกจ · ออฟเฟอร์ · ช่องทางรับออเดอร์ · โทนดีไซน์ · ข้อมูลที่ยังไม่มี — แล้ว AI จะพาไปจนถึงหน้าเว็บพร้อมขาย
